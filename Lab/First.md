# Первая лабораторная работа

Чтобы настроить сеть с двумя подсетями на MikroTik в GNS3, нужно выполнить три основных шага: построить топологию, назначить IP-адреса интерфейсам и настроить компьютеры.

**Теория:** [Теоретический конспект к первой лабораторной](../Notes/Теоретический%20конспект%20к%20первой%20лабораторной.md). Среда: [Настройка GNS3](../Theory/Настройка%20GNS3.md).

На компьютере должны быть установлены GNS3 и Virtualbox.

### Шаг 1: Сборка топологии в GNS3

В GNS3 откройте Setup Wizard. При первом запуске программы открывается автоматически. Иначе Help -> Setup Wizard. Выберите пункт Run appliencies in a virtual machine (Потребуется скачать и запустить в Virtualbox образ GNS VM). Для Ubuntu допустим пункт Run appliencies on my local computer (Требует наличия qemu и dynamips). Убедитесь что все образы (маршрутизаторы и рабочие станции) запускаются либо на virtualbox, либо в qemu. Одновременный запуск вызовет конфликт за доступ к аппаратной виртуализации.

- Скачайте образ виртуального жесткого диска (.vdi) с официального сайта [Mikrotik](https://mikrotik.com/download/chr). Например Mikrotik CHR 7.23 или любой другой аналгичный.
- Добавьте в Virtualbox новый виртуальный носитель: Файл -> Инструменты -> Носители -> Добавить.
- Создайте новую виртуальную машину. Не добавляйте образ диска (.iso). Выберите добавленный образ жесткого диска (.vdi)

Создайте проект и соберите в нем сеть по следующей схеме:

*   **Устройства:**
    *   Один роутер **MikroTik** (`MikroTik CHR`) .
    *   Два компьютера **VPCS** (Virtual PC Simulator) — по одному для каждой подсети .
    *   Два коммутатора **Ethernet Switch** (по одному на подсеть, опционально, но помогает структурировать сеть) .
*   **Схема подключения:**
    *   **Подсеть 1 (Red):** Компьютер PC1 → Коммутатор Switch1 → `ether1` роутера .
    *   **Подсеть 2 (Blue):** Компьютер PC2 → Коммутатор Switch2 → `ether2` роутера .

Визуально разделите подсети с помощью фигур и подписей, чтобы не запутаться .

### Шаг 2: Базовая настройка роутера MikroTik

После сборки топологии, запустите все устройства и откройте консоль роутера. По умолчанию логин — `admin`, пароль пустой .

1.  **Назначьте IP-адреса интерфейсам**, которые подключены к разным подсетям. Эти адреса будут шлюзами для компьютеров.
    *   Для интерфейса `ether1` (подсеть 1):
        ```text
        /ip address add address=172.16.10.254/24 interface=ether1
        ```
    *   Для интерфейса `ether2` (подсеть 2):
        ```text
        /ip address add address=172.16.20.254/24 interface=ether2
        ```
    *   Проверьте настройку командой `ip address print` .

2.  **Настройте имя роутера** (опционально) для удобства :
    ```text
    /system identity set name=My-MikroTik-Router
    ```

### Шаг 3: Настройка компьютеров (VPCS)

Теперь нужно настроить сетевые параметры на каждом виртуальном ПК.

*   **Настройка PC1 (Подсеть 1):**
    *   В консоли PC1 введите команду, где сначала указывается IP-адрес, а затем шлюз по умолчанию .
    ```text
    ip 172.16.10.1/24 172.16.10.254
    ```
    *   Сохраните конфигурацию: `save`.

*   **Настройка PC2 (Подсеть 2):**
    *   В консоли PC2 введите команду:
    ```text
    ip 172.16.20.1/24 172.16.20.254
    ```
    *   Сохраните конфигурацию: `save`.

### Шаг 4: Проверка работоспособности

Самое главное — убедиться, что сеть работает.

1.  **Проверка на PC1** :
    *   Пингуем свой шлюз (роутер): `ping 172.16.10.254` — должен быть успешным.
    *   Пингуем интерфейс роутера во второй подсети: `ping 172.16.20.254` — должен быть успешным.
    *   Пингуем PC2, чтобы убедиться, что роутер выполняет маршрутизацию между подсетями: `ping 172.16.20.1` — должен быть успешным.

Если все пинги прошли успешно, значит, роутер MikroTik успешно связал две ваши подсети в GNS3.

### Домашнее задание

Сдать к следующей встрече:

1. Схему топологии (рисунок или скрин GNS3) с подписями подсетей и устройств.
2. Таблицу IP-адресов: PC1, PC2, оба интерфейса MikroTik.
3. Подтверждение трёх успешных ping из шага 4 (скрин или краткий лог).
4. Текст на 3–5 предложений: зачем между двумя подсетями нужен маршрутизатор (почему недостаточно одного коммутатора).
